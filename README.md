# سیستم جامع انتخاب واحد - بخش فرانت‌اند (Frontend)

این مخزن شامل کدهای سمت کاربر (Frontend) پروژه درس مهندسی نرم‌افزار است که با استفاده از HTML5، CSS3 و JavaScript (Vanilla JS) پیاده‌سازی شده است.

## پیش‌نیازها
برای اجرای صحیح پروژه و برقراری ارتباط با API، اطمینان حاصل کنید که:
1. **بکند (Backend)** پروژه در آدرس `http://127.0.0.1:8000` در حال اجرا باشد.
2. مرورگر شما از جاو‌اسکریپت پشتیبانی کند.

## نحوه اجرا

شما می‌توانید به دو روش زیر پروژه را اجرا کنید:

### روش اول: استفاده از VS Code Live Server (توصیه شده)
اگر از ویرایشگر VS Code استفاده می‌کنید:
1. افزونه **Live Server** را نصب کنید.
2. روی فایل `login.html` راست کلیک کرده و گزینه **Open with Live Server** را انتخاب کنید.
   - این کار پروژه را روی آدرس `http://127.0.0.1:5500` اجرا می‌کند.

### روش دوم: استفاده از پایتون (بدون نیاز به نصب ابزار اضافه)
اگر پایتون روی سیستم شما نصب است، در ترمینال یا CMD وارد پوشه فرانت‌اند شوید و دستور زیر را تایپ کنید:

```bash
# برای پایتون نسخه 3 به بالا
python -m http.server 5500
