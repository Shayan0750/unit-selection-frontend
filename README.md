# 🎓 سامانه انتخاب واحد (بخش فرانت‌اند)

این مخزن شامل کدهای سمت کاربر (Frontend) سامانه انتخاب واحد است که با استفاده از HTML5، CSS3 و Vanilla JavaScript پیاده‌سازی شده و به صورت امن با APIهای بک‌اند در ارتباط است.

---

## 🚀 راهنمای راه‌اندازی و اجرا

به دلیل استفاده از **ماژول‌های جاوااسکریپت** و درخواست‌های **API**، پروژه باید حتماً بر روی یک وب‌سرور (Local Server) اجرا شود تا با خطای CORS یا محدودیت‌های فایل محلی مواجه نشوید.

### روش اول: استفاده از VS Code Live Server (پیشنهادی)

اگر از ویرایشگر VS Code استفاده می‌کنید، بهترین راه استفاده از افزونه **Live Server** است:

1. **نصب افزونه:** کلیدهای `Ctrl+Shift+X` را زده و عبارت **Live Server** (اثر Ritwick Dey) را نصب کنید.
2. **اجرا:** - روی فایل `index.html` راست کلیک کرده و گزینه **Open with Live Server** را بزنید.
   - یا از نوار پایین (Status Bar) روی دکمه **Go Live** کلیک کنید.
3. **میانبر:** کلیدهای `Alt+L` و سپس `Alt+O` سرور را باز می‌کنند.
